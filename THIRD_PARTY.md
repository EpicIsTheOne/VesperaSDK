# Third-party components

The connector uses HTTPX (BSD-3-Clause), keyring (MIT), and platformdirs (MIT).
Their runtime dependencies retain their own licenses. PyInstaller packaging includes its bootloader,
covered by the PyInstaller license and bootloader exception, which permits distributing bundled applications.
Consult each installed distribution's license metadata when redistributing a build.

* https://github.com/encode/httpx
* https://github.com/jaraco/keyring
* https://github.com/tox-dev/platformdirs
* https://pyinstaller.org/en/stable/license.html

No CLIProxy binary or subscription account credentials are bundled. CLIProxy remains a separate installation.
No proprietary Vespera server code is included in this repository.
